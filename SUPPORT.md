# Support

For questions, bug reports, and feature requests, please open an issue in the [GitHub repository](https://github.com/noritaka1166/vscode-appium-inspector-bridge/issues).

Before opening an issue, please check that you are using the latest extension release and include the following information where applicable:

- Extension version and VS Code version
- Operating system
- Appium and Appium Inspector plugin versions
- Whether the Appium Server was started by this extension or externally
- Relevant error messages and the **Appium Inspector Bridge** output log
- Steps to reproduce the problem

Please do not include credentials, access tokens, application binaries, or other sensitive data. Report potential security vulnerabilities according to [SECURITY.md](SECURITY.md) instead of creating a public issue.
